## 項目簡介

**Object Storage 騰訊雲 COS 組件** - 提供 Object Storage 組件的騰訊雲物件儲存（COS）實作。本套件實作了騰訊雲 COS 的上傳管理器，允許您上傳檔案和目錄到騰訊雲 COS 儲存桶。

## 快速開始

### 安裝方式

任選其一：

1. 直接在 `manifest.json` 的文件中的 `dependencies` 節點下新增以下內容
   ```json
   {"com.gameframex.unity.objectstorage.tencent": "https://github.com/AlianBlank/com.gameframex.unity.objectstorage.tencent.git"}
   ```
2. 在 Unity 的 `Packages Manager` 中使用 `Git URL` 的方式新增庫，地址為：https://github.com/AlianBlank/com.gameframex.unity.objectstorage.tencent.git
3. 直接下載倉庫放置到 Unity 專案的 `Packages` 目錄下，會自動載入識別。

### 使用範例

參照父組件 [Object Storage](https://github.com/GameFrameX/com.gameframex.unity.objectstorage) 的使用文檔。
